# 로또

## 기능 목록

### 로또 구매

-   [x] 로또 구입 금액을 입력받는다.
    -   [x] 입력값이 숫자가 아닐 경우 예외를 발생시킨다.
    -   [x] 구입 금액이 1,000원 단위가 아닐 경우 예외를 발생시킨다.
-   [x] 구입 금액에 해당하는 만큼 로또를 발행한다.
-   [x] 발행된 로또의 개수와 번호를 출력한다.
    -   [x] 로또 번호는 오름차순으로 정렬하여 출력한다.

### 당첨 번호 및 보너스 번호 입력

-   [x] 당첨 번호 6개를 쉼표(,)로 구분하여 입력받는다.
    -   [x] 당첨 번호가 6개가 아닐 경우 예외를 발생시킨다.
    -   [x] 당첨 번호에 중복된 숫자가 있을 경우 예외를 발생시킨다.
    -   [x] 당첨 번호가 1~45 사이의 숫자가 아닐 경우 예외를 발생시킨다.
    -   [x] 입력값에 숫자가 아닌 문자가 포함된 경우 예외를 발생시킨다.
-   [x] 보너스 번호 1개를 입력받는다.
    -   [x] 보너스 번호가 1~45 사이의 숫자가 아닐 경우 예외를 발생시킨다.
    -   [x] 보너스 번호가 당첨 번호와 중복될 경우 예외를 발생시킨다.
    -   [x] 입력값이 숫자가 아닐 경우 예외를 발생시킨다.

### 당첨 결과 확인

-   [x] 구매한 모든 로또에 대해 당첨 결과를 계산한다.
-   [x] 당첨 통계를 등수별로 집계한다.
    -   1등: 6개 번호 일치
    -   2등: 5개 번호 + 보너스 번호 일치
    -   3등: 5개 번호 일치
    -   4등: 4개 번호 일치
    -   5등: 3개 번호 일치
-   [x] 당첨 내역을 형식에 맞게 출력한다.
-   [x] 총 수익률을 계산하여 출력한다.
    -   [x] 수익률은 소수점 둘째 자리에서 반올림한다.

## 프로그래밍 요구 사항

### 실행 환경
- Node.js 22.19.0 이상

### 코드 컨벤션
- [JavaScript Style Guide](https://google.github.io/styleguide/jsguide.html) 준수
- `indent` depth는 2까지만 허용 (3 이상 금지)
- 3항 연산자 사용 지양
- `else` 문 지양
- 함수(또는 메서드)는 한 가지 일만 하도록 작게 구현 (15라인 이하)

### 테스트
- Jest를 사용하여 기능 목록에 대한 단위 테스트 작성
- UI 관련 로직(Console API)은 테스트에서 제외

### 라이브러리
- `@woowacourse/mission-utils`의 `Random` 및 `Console` API 사용
- 외부 라이브러리 추가 사용 금지

### 제약 사항
- `package.json` 파일 변경 금지
- `App.js`의 `run()` 메서드를 프로그램 시작점으로 사용
- `process.exit()` 호출 금지
- 제공된 `Lotto` 클래스 활용
    - `numbers` 외 필드 추가 금지
    - `#numbers` 접근 제어자 변경 금지

## 실행 방법

1.  **저장소 복제**
    ```bash
    git clone https://github.com/{본인_계정}/{저장소_이름}.git
    cd {저장소_이름}
    ```

2.  **의존성 설치**
    ```bash
    npm install
    ```

3.  **테스트 실행**
    ```bash
    npm run test
    ```

4.  **애플리케이션 실행**
    ```bash
    npm run start
    ```
